# Weather Dashboard

A lightweight weather dashboard built with plain HTML, CSS, and JavaScript.

## Features
- Search by city name
- Current weather conditions
- Feels-like temperature, humidity, and wind speed
- Hourly forecast for the next several hours
- 7-day forecast
- Uses the public Open-Meteo API with no API key required

## Run locally
1. Open `index.html` directly in a browser, or
2. Serve the project locally:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Files
- `index.html` — dashboard markup
- `style.css` — dashboard styling
- `script.js` — weather API logic

## API
This app uses the public Open-Meteo API:
- https://open-meteo.com/
